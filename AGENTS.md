# DNU project guidance

Before changing story collection, selection, placement, presentation or export, read [the editorial policy](public/editorial-policy.md). It is the project’s consolidated brief and is published through the website’s **Editorial policy** link. Treat the latest direct user instruction as superseding a conflicting policy item, then update the policy and the relevant implementation together.

The policy describes intended behavior. Verify the current code and prepared edition before claiming that a rule is enforced or that a source was checked. Never put API keys or passwords into the policy or the repository.
